## Objective

r04 영상의 빈 회색 카드 10곳을 AI 생성 한국인 모델 사진으로 채우고, 한국어 문구 아래에 작은 영어 표기를 붙인 이중 표기판(r05)을 렌더한다.

## Evidence

- 저장소에 광고용 사진 없음: 상품 이미지는 KREAM 외부 링크(타사 사진), 자체 이미지는 `public/home-banner.jpg` 1장뿐.
- 사진 슬롯 10곳: 스크롤 피드 카드 4 · AI STUDIO 카드 1(현재 회색 실루엣) · STYLE IT 카드 4 · SHARE IT 카드 1. 모두 `card()` 또는 S07 실루엣 도형.
- 한국어 문구 위치: 스크롤 가사 4단어 · 톡! · 짠! · 밤티/말고(후렴1·3) · 오늘은 · 밤티 말고(보조) · 빠/밤!
- 사진 생성: Higgsfield Soul 2.0, 총 20회 생성(약 2.4 크레딧) — 얼굴 잘림·가짜 글자·앱 화면 컷 10건 재생성, 1장은 테두리 잘라냄. 최종 10장 = `marketing/launch-teaser/photos/`.

## Spec

- 사진: `marketing/launch-teaser/photos/` 에 저장(AI 생성물, 저장소 커밋 대상). 경로는 `00-core.jsx` 의 `PHOTO_DIR` 상수(배너 경로와 같은 방식).
- `card(o)` 에 `o.photo`(푸티지) 추가 — 이미지 영역을 덮도록(cover) 스케일하고 둥근 사각형 마스크로 자른다. 사진이 없으면 지금처럼 회색 도형(예외 없이 명시적 분기).
- S07: 실루엣 대신 전신 사진, 스캔라인은 그 위로 지나간다.
- 이중 표기 helper `gloss(str, o)` — enMid, 작게, tracking 넓게, 한국어 단어 바로 아래·같은 등장 시각+2프레임 typeOn.

## Success Criteria

1. 사진 10장이 각 카드 이미지 영역에 잘림 없이 채워지고 얼굴이 프레임 안에 있다 — 확인: r05 프레임 육안
2. 한국어 문구 9곳 모두 아래에 영어 표기가 보이고 다른 요소와 겹치지 않는다 — 확인: r05 프레임 육안
3. AE 실행이 오류 없이 끝나고 mp4 가 40.88s · 1080×1920 · 오디오 포함이다 — 확인: 직접 실행 + ffprobe
4. 사진이 없을 때 기존 회색 카드로 그려진다(빌드 회귀 없음) — 확인: 코드 분기 확인
