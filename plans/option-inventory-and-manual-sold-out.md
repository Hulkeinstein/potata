# 옵션 재고와 수동 품절 관리 계획

## 목표

색상·사이즈 조합별 재고를 관리하고, 재고와 무관하게 관리자가 원하는 상품 또는 옵션을 즉시 품절로 바꿀 수 있게 한다.

## 상태 규칙

- **판매 중**: 활성 옵션의 재고가 1 이상이고 수동 품절이 아님.
- **자동 품절**: 옵션 재고가 0.
- **수동 품절**: 재고가 남아 있어도 관리자가 강제로 구매를 막음.
- **전체 품절**: 모든 판매 옵션이 자동 또는 수동 품절.
- **판매 중지**: 기존 `isActive=false`; 고객 목록과 직접 주소에서 숨김.

수동 품절을 해제하면 재고가 남은 옵션은 즉시 판매 중으로 복귀하고, 재고 0 옵션은 계속 자동 품절이다.

## 범위

- 옵션 재고 모델과 additive migration
- 관리자 등록·수정 화면의 옵션별 수량/수동 품절 제어
- 고객 상세 화면의 옵션 선택·품절 표시·구매 차단
- 장바구니와 주문 생성 시 서버 재검증 및 재고 원자 차감
- 경쟁 주문에서 재고가 음수가 되지 않도록 transaction 조건부 차감
- 관리자 목록에 판매 중/품절/판매 중지 상태와 재고 요약 표시

## 제외

- 결제 provider, 예약 재고, 환불 자동 복구, 다창고, 입고 발주, 재입고 이메일 알림, 실제 삭제

## 검증

- 옵션 재고 0/양수, 수동 품절 전환·해제, 전체 품절 계산
- 비활성 상품 차단, 품절 옵션 장바구니/주문 차단, 동시 주문 재고 초과 방지
- desktop/mobile 관리자·고객 QA, migration, typecheck, lint, 전체 tests, production build
